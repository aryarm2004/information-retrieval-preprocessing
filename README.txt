# راهنمای اجرای پروژه


**۱. نصب کتابخانه موردنیاز:**

```bash
python -m pip install -r requirements.txt
```

**۲. اجرای برنامه:**

```bash
python Ahmad_Rahimi Moghaddam.py
```

پس از اجرا، خروجی مراحل مختلف پردازش، مقادیر Precision و Recall و خطاهای احتمالی در ترمینال نمایش داده می‌شوند. همچنین نتایج نهایی هر سه متن در فایل `outputs.json` ذخیره خواهند شد.
